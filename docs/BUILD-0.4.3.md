# SPSir 0.4.3

交付日期：2026-10-06。版本 0.4.3，versionCode 8。

## 改动

- 公共事件结算页支持实际转账的新增、编辑、删除；建议可预填表单，确认保存才记入。支持部分、多次、非建议路径和超额转账，超额保存前确认。
- 剩余净额使用整数最小单位计算：费用实付额 − 应承担额 + 已转出 − 已收到。正数应收、负数应付，重新生成稳定的转账建议。空事件与已结清事件分别显示。
- 转账独立保存，不进入个人收入支出，不增加事件消费总额。个人流水仍只记录本人承担的费用。
- 个人和公共事件支持改名、归档、取消归档；默认隐藏归档事件。未结清归档需确认，归档不影响历史统计。费用、成员和转账在界面与事务写入层均受归档保护。
- 公共账单先预览，再通过系统面板分享文本文件或保存 UTF-8 文本。默认只有结算摘要，明细与备注主动勾选。账单取自同一份快照，取消、失败均不修改账本。文字账单不能用于恢复数据库。
- 新表单提供未保存修改保护、删除确认和保存状态恢复；保持原有“开支／结算”布局和底部导航。

## 兼容性

- Room 数据库版本 3 → 4：增量加入事件归档字段与转账表，保留旧记录和关系，无破坏性迁移。
- 完整备份格式 3，继续读取格式 1、2；旧事件默认未归档、转账为空。恢复检查事件、成员、金额、日期和重复 ID；保留恢复前副本及统一 20 MiB 容量限制。
- 应用 ID `com.spsir.ledger`、应用名 SPSir 和原有签名不变。更新前导出完整备份，直接覆盖安装，不先卸载。升级后的数据库和备份不应交给旧版本恢复。
- 未加入退款、预算、不等额分摊、复制一笔、支付识别、账号或联网同步；未新增第三方依赖。
