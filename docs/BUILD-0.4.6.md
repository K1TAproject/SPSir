# SPSir 0.4.6

日期：2026-10-17。versionCode 11。

## 功能

- 「记一笔」的“最近使用”不再按使用时间取最近几项，改为按记账笔数排序：先比次数多的，次数相同再比最近一次记账日期新的，仍相同按预设分类顺序，保证列表稳定。
- 收入分类、已隐藏分类和旧分类（零食水果、公交地铁等原分类）仍不进入候选；上限仍是 6 项。
- 打开新增表单时默认选中的分类随之改为最常用的一个，分类选择面板和筛选结果不受影响。
- 统计仍按全部流水计算；本次不新增“指定时间段内的常用分类”或列表展示次数。

## 兼容

- 只改变候选排序，不新增数据表或字段。Room 数据库仍为版本 4，完整备份格式仍为 4，继续读取格式 1～3。
- 分类 ID、流水、隐藏设置、事件与公共结算均不变；升级前导出的备份在新版仍可恢复，新版备份与 0.4.5 互通。
- 版本为 0.4.6 / 11，使用现有正式签名；已安装正式版 0.4.5 可覆盖安装并保留账本。旧调试版仍需先备份后迁移，不要因签名冲突直接卸载。

发布时使用 release 目录中的 `SPSir-0.4.6.apk` 和同次构建的 `update.json`，标签 `v0.4.6`。本次不提交、推送或发布。
