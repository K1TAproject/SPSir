# 0.4 公共事件开发与验证

完成日期：2026-10-05。应用版本：0.4.0（versionCode 5）。

## 已实现

- 新建个人／公共事件；公共事件自动包含“我”，支持添加、改名和移除未被费用引用的同行者。
- 录入项目总额、付款人和分摊参与者；付款人可不参与消费，支持仅自己承担或仅其他成员承担。
- 原币和手动人民币金额分别按整数最小单位均分，按稳定成员顺序处理尾差。
- 事件总额、我的支出、事件类别占比、成员应承担／已付及人民币净额转账建议。
- 本人份额与个人流水通过唯一关联和事务同步保存、修改、删除。从个人流水打开同一公共费用编辑界面。
- 备份格式升级至 2，包含公共事件数据；继续读取格式 1。校验成员、参与者、付款人及派生流水一致性，异常文件不覆盖账本。
- Room 数据库升级至 3，提供 2 → 3 迁移并保留 1 → 2 路径；旧事件和个人流水保持原有含义。

- 19 项 JVM 单元测试通过，其中新增 6 项分摊与结算测试。

- 覆盖完整旅行算例、尾差与零份额、多债权人净额结算、溢出拒绝、重复保存、修改参与者、付款人变更、删除联动、引用成员保护。
- 覆盖 1 → 3、2 → 3 数据迁移；公共数据备份往返、旧备份恢复、异常文件拒绝，以及注入数据库失败时的保存／恢复事务回滚。
- 覆盖公共事件创建、首页金额转入公共费用、本人不参与、个人流水跳转原费用、删除确认以及 1.5 倍字号下的成员改名。
- 最终参与者触控区域调整后，4 项公共事件界面测试再次全部通过，截图已更新。

完整算例：事件合计 ¥1,770.00；本人承担 ¥730.00；甲应向本人转 ¥295.00，乙应向本人转 ¥355.00。本人流水只有住宿 ¥400.00、晚餐 ¥150.00、胶卷 ¥180.00，不把收到垫付款再计为收入。

## 入口与边界

“事件 → 新建事件 → 公共事件”添加同行者；事件内“记开支”填写总额、付款人和参与者；“结算”查看转账建议。

本版为单机多人均分，单笔单人付款。暂不支持多设备协作、自定义份额、多人共同付款、退款及已转账状态；结算建议明确提示“未扣除成员间已转账”。普通个人事件继续使用已经 AA 的个人金额，不自动转换历史记录。

安装包由根目录 `build-apk.cmd` 或 `scripts/Build-Apk.ps1` 生成，输出 `app/build/outputs/apk/debug/SPSir.apk`。这是带调试签名的个人试用包，最低 Android 8.0。安装说明见 [INSTALL-ANDROID.md](INSTALL-ANDROID.md)。

最终安装包大小：12,173,358 字节；APK v2 签名验证通过。
