# 0.3 日常可用版：记账体验、备份恢复与流水查找

状态：已实现并完成开发验证，待实体手机试用  
日期：2026-10-03  
项目：随手账本（SPSir）

## 一、目标与背景

当前已具备手动记账、预设分类、事件归集、外币金额保存、日／周／月／年统计及第一版 UI。下一阶段优先解决日常使用中的三个问题：常见支出录入步骤较多、账本尚不能自行备份恢复、历史流水缺少搜索和筛选。

0.3 的目标是让用户能够顺畅记录日常开销，快速找到并修改历史记录，并通过本地备份保留完整账本。

## 二、延续的产品约束

- Android 应用，沿用 Kotlin、Jetpack Compose、Room / SQLite。
- 所有收入支出由用户手动录入，不加入自动识别和自动汇率。
- 外币记录保存原币金额、币种和手动填写的人民币金额；统计统一使用人民币金额。
- 只记录个人承担金额，默认已完成 AA，不处理多人分摊。
- 事件支出与全部流水使用同一笔记录，统计不得重复计算。
- 收入保留简单入口，不引入账户余额管理。
- 保留现有预设分类及历史分类兼容关系，不重置用户数据。
- 延续当前界面风格，支持在电脑模拟器中预览与验证。

## 三、本版功能范围

### A. 记账体验优化

#### A1. 优先输入金额

- 新增记录时，让金额成为清晰的首要输入项，适配数字键盘。
- 人民币记录只填写一次金额；切换外币后同时提供原币金额和人民币金额。
- 支出／收入切换、编辑已有记录、保存错误提示沿用现有业务规则。
- 键盘弹出时仍能滚动至必要字段并完成保存，避免遮挡关键操作。

#### A2. 日期选择

- 将记账日期输入改为日历选择，默认今天。
- 编辑记录时显示原日期，支持回到今天。
- 历史日期可正常选择；保存后流水排序和周期统计同步更新。

#### A3. 分类选择

- 提供“大类 → 细类”的选择面板，清晰显示当前选项。
- 展示最近使用的支出细类，允许直接选择；数量以少量、易点击为原则。
- 增加类别显示管理：可隐藏／恢复不用的大类或细类，不删除分类。
- 隐藏仅影响新录入时的候选项和快捷入口，不影响已有流水、统计与备份。
- 编辑历史记录时，即使原分类被隐藏，也能看到并保留原分类。
- 收入继续使用一个通用分类，不扩展复杂收入体系。

### B. 本地备份与恢复

#### B1. 导出备份

- 用户主动选择保存位置，导出可恢复的完整账本文件。
- 建议使用带格式版本号的 UTF-8 JSON 文件，包含导出时间及必要数据。
- 备份至少包括：全部流水、事件、分类、分类隐藏状态；保留各记录 ID 与关联关系。
- 流水需完整保留收支类型、原币最小单位金额、币种、人民币最小单位金额、日期、备注、分类 ID 和事件 ID。
- 金额按整数最小货币单位保存，不通过浮点数往返转换。
- 导出成功与失败均给出明确反馈；取消文件选择不改变账本。

#### B2. 恢复备份

- 用户主动选择备份文件，先校验格式版本、必填字段、金额、币种、日期、ID 唯一性及分类／事件引用完整性。
- 确认前显示备份时间和流水、事件数量，并明确说明恢复的影响。
- 本版采用整本覆盖恢复，不实现合并去重；覆盖必须由用户明确确认。
- 覆盖前保留当前账本的可恢复副本；副本保存失败时不继续覆盖。
- 恢复过程使用数据库事务，失败时回滚，避免出现部分写入。
- 遇到损坏文件或不支持的格式版本时拒绝恢复，原账本保持不变。
- 恢复成功后刷新流水、事件和统计；重启应用后数据仍完整。

### C. 流水分组、搜索与筛选

#### C1. 按日期分组

- 流水按记账日期倒序分组。
- 日期标题显示该日支出合计，统一使用人民币。
- 使用筛选时，分组金额按当前结果计算，并标明当前筛选范围。

#### C2. 搜索与组合筛选

- 支持按备注关键词查找流水。
- 支持日期范围、收入／支出、大类／细类、事件条件。
- 支持多条件组合，展示当前条件、结果笔数与人民币收支合计。
- 提供一键清除筛选和无结果提示。
- 搜索历史流水时允许跨月查询，不受首页当前月份隐式限制。
- 从结果进入已有编辑流程；修改或删除后立即重新计算结果与合计。

## 四、验收标准

### 记账与分类

- [x] 能完成一笔三餐支出和一笔摄影支出的新增、编辑与保存。
- [x] 最近使用的分类可直接选择，不用重复进入大类选择。
- [x] 日历选择的日期正确保存，跨月修改后统计归属正确。
- [x] 人民币和外币金额输入均正常，外币不自动换算。
- [x] 隐藏分类后，新录入不再出现该选项；历史流水和统计金额保持不变。
- [x] 恢复分类显示后可再次选择；历史记录原有隐藏分类可保留。
- [x] 键盘弹出、表单滚动和保存操作无明显遮挡。

### 数据备份

- [x] 含收入、支出、外币、事件及隐藏分类的账本能够完整导出并恢复。
- [x] 恢复前后记录 ID、金额、日期、备注及关联关系一致，各周期统计一致。
- [x] 用户取消选择或取消确认时，原账本不变。
- [x] 损坏文件、重复 ID、缺失引用及不支持的格式版本不会覆盖现有账本。
- [x] 覆盖前旧账本副本可恢复；恢复失败不会留下部分数据。
- [x] 恢复后重启应用，账本仍完整。

### 流水查找

- [x] 能通过关键词找到跨月份的历史备注记录。
- [x] 日期、收支类型、类别、事件筛选可组合使用，清除后恢复默认列表。
- [x] 结果笔数、每日分组金额及结果合计与实际记录一致。
- [x] 修改日期／分类／事件或删除记录后，搜索结果与统计同步更新。
- [x] 空结果显示明确提示，不显示错误占比或误导金额。

### 回归与交付

- [x] 现有记账、事件、外币与统计测试通过。
- [x] 为备份往返一致性、恢复失败回滚及组合筛选增加必要测试。
- [x] 如需调整数据库结构，提供保留旧数据的迁移，不清库重建。
- [x] 在模拟器检查主要页面、键盘状态及长列表，保存验证截图。
- [x] 更新 README 与本版验证说明。

## 五、建议实施顺序

1. 先完成备份与恢复，验证账本能够完整往返保存。
2. 完成金额／日期／分类录入优化，验证旧记录编辑与分类兼容。
3. 完成流水分组、搜索及筛选，核对金额与事件统计。
4. 完成回归检查后试记一周，根据实际使用问题安排后续调整。

## 六、本版之外

事件改名、结束状态与复盘备注，以及从统计图直接进入对应流水，可放到下一阶段。暂不开发云同步、多人协作、账户余额、自动录入、自动汇率、预算、完整自定义分类或复杂收入管理。

本版实现、自动测试及模拟器验证见 [0.3 验证记录](BUILD-0.3.md)。实体手机试用与一周真实记账仍待用户安装后验证。
