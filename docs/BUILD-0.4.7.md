# SPSir 0.4.7

日期：2026-10-25。versionCode 12。

## 实现与口径

- 将统计范围从 StatisticsPanel 内部移到 LedgerViewModel / LedgerState，两个页面读取同一状态。使用独立 SharedPreferences 保存模式和事件 ID，不写入事件或完整备份。
- 成功读取数据库快照后才校验事件 ID；不存在时恢复全部。改名、归档与取消归档不改变选择。恢复备份只有在数据库事务成功后重置范围。
- 共用一个范围入口与选择对话框。默认全部；仅含/排除必须显式选择事件，不自动选第一个。取消、外部关闭、系统返回放弃草稿；“恢复全部”将草稿改为全部，点击应用后生效。
- 流水按月份或搜索条件展示完整记录；月度卡片始终按选定月份统计。每日、搜索结果与统计页汇总共用同一事件判断。范围生效时每日小计标为“当日统计支出”，统计卡片显示“计入统计 X 笔”。
- 搜索与统计范围冲突时仍显示记录，标记“不计入统计”，金额为零并提示调整统计范围。统计页趋势和分类占比（含下钻）均来自同一筛选后集合。
- 公共事件只筛选本人流水份额，成员转账不纳入个人消费。事件列表、事件详情、公共结算、事件账单始终使用完整原始数据。
- 日期各自独立，范围跨页面/日期/重启保持；收入沿用原有不关联事件的规则，仅含事件时无事件收入不纳入统计。
