# 0.2 分类与统计验证记录

日期：2026-10-02。项目：`D:\SPSir`，版本：0.2.0。

## 本次功能

- 13 个支出大类、110 个可选细分类别；收入仍只有通用收入。完整列表见 [预设分类](CATEGORIES.md)。
- 手机话费与流量包分开；三餐、宵夜、胶卷、冲洗、扫描、器材购买和保养维修分别记录。
- 日、周、月、年收支金额与差额，支持日期选择、前后周期及返回当前周期。
- 收入／支出双柱趋势图，点击查看金额，展开精确明细；分类金额、占比与细分类别下钻。
- 事件中的分类占比复用同一组件，事件流水只计入全局一次。

## 统计口径

所有汇总使用手动录入的人民币金额，不重新换算原币。差额为收入减支出，不表示账户余额。周为周一至周日，月和年为完整自然月、自然年；缺少记录的日期仍显示零值。日度只有当天汇总，不虚构未保存的小时信息。

类别占比先按本期收入或支出总额计算；进入某大类后，按该大类金额计算细类占比。空数据不绘制虚假比例。小于 0.1% 的非零占比显示为 `<0.1%`。

## 兼容性

保持 Room 数据库结构版本 1，分类通过保留原 ID 的更新／插入补齐。旧“零食水果”“公交地铁”保留为原分类，旧记录可继续编辑，新录入使用拆分后的细类。旧“冲洗扫描”保留为套餐分类，不擅自拆分历史金额。

更新前后实际模拟器账本核对一致：流水 0 笔、事件 0 个；分类由 27 行更新为 126 行（包含大类、可选细类、2 个兼容旧细类及通用收入）。带有历史流水和事件的兼容升级另由独立数据库测试验证，重复初始化不会增加重复分类或修改流水。

## 验证结果

- 编译应用与测试调试包成功。
- 11 项 JVM 单元测试通过，覆盖金额、日期、跨年周、闰年二月、零值补齐、人民币汇总、类别占比和预设分类完整性。
- 8 项 Android 35 设备测试通过，覆盖 Room 持久化、分类升级、手动录入、日期切换、类别下钻和空状态。
- Android Lint：0 errors、4 warnings，仍为原有 SDK／Gradle 版本及正式图标提示。
- 更新安装保留应用数据，应用已在 `SPSir_API35` 模拟器中启动。未生成正式签名发布包。

构建日志位于 `.local/statistics-verified-build.log`，设备测试日志位于 `.local/statistics-device-tests.log`。
