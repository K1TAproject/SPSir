## 实现

- 独立正式签名与非调试 Release 构建，`build-release.cmd` 生成带版本文件名的 APK 及配套 update.json。原调试构建入口保留。

- 网络只读取 GitHub 公开 Release 元数据，设置连接/读取超时、响应大小限制和 HTTPS 主机检查。异常不影响账本。
- 以安装包的整数 versionCode 比较版本，校验最低系统版本、应用 ID、标签和 APK 附件。手动检查绕过自动间隔及忽略状态。
- 签名由用户明确选择新建；其文件与密码配置位于已忽略的 .local 目录，不提交、不上传。

首次切换必须先导出完整备份，再卸载旧调试版、安装正式版、恢复并核对；不能直接覆盖旧签名。之后的正式包沿用本次签名更新。

测试不向 GitHub 发布测试版本，也不向任何人发送消息。线上新版本发现与实际浏览器下载仍需发布更高版本后在手机验证。当前不会为了安装正式包清空已有模拟器账本；设备回归使用同源码的调试包。
