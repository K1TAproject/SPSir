# SPSir 0.4.4

- 增加启动版本检查，可在工具页关闭；自动检查每 24 小时最多一次。
- 支持手动检查更新、查看发布说明、忽略当前版本和浏览器下载。
- 账本继续保存在本地，版本检查仅访问 GitHub，不上传账本。
- 正式包使用独立发布签名，后续正式版本沿用此签名更新。

**从旧调试版首次切换：先导出完整备份并妥善保存，再卸载旧版、安装正式版并恢复。新正式签名无法直接覆盖旧调试签名。**

Android 8.0 及以上。数据库和备份格式不变。无账号、同步、后台推送、App 内下载或自动安装。

Release 附件必须同时包含 `SPSir-0.4.4.apk` 和 `update.json`；后者供版本检查读取。旧版 0.4.3 不含更新检查，首次需手动下载。
