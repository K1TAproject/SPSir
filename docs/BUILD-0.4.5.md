# SPSir 0.4.5

日期：2026-10-11。versionCode 10。

## 功能

- 记一笔切换到收入后，可选择生活费、家教费、返现、工资奖金、红包礼金，以及原通用“收入”类别。旧记录不自动猜测分类，编辑时可手动调整；收入占比按新类别分别展示。
- 统计页新增“全部事件／仅含指定事件／排除指定事件”，可选择个人、公共或已归档事件。日、周、月、年的收支总额、差额、笔数、趋势及分类占比共用筛选结果。
- “全部事件”包含无事件流水；排除指定事件保留无事件流水。公共事件只计算用户本人已经进入流水的份额，成员转账不计为消费。筛选不修改流水、归档状态或公共结算。
- 收入沿用现有规则，不关联事件，因此“仅含指定事件”不会包含未关联收入。筛选状态支持界面状态恢复，不作为账本的永久排除规则。

## 兼容

- Room 数据库仍为版本 4；新增预设分类通过现有 Upsert 补齐，保留旧类别 ID、流水和关联。
- 完整备份格式升为 4，继续读取格式 1、2、3。新备份不可交给 0.4.4 或更旧版本恢复。恢复前副本和 20 MiB 容量限制不变。
- 版本为 0.4.5 / 10，使用现有正式签名；已安装正式版 0.4.4 可覆盖安装。旧调试版仍需先备份后迁移，不要因签名冲突直接卸载。
- 本次不添加自定义分类、自动归类、退款冲销或多人同步。返现作为手工收入记录，不自动修改原支出。

发布时使用 release 目录中的 `SPSir-0.4.5.apk` 和同次构建的 `update.json`，标签 `v0.4.5`。本次不提交、推送或发布。
