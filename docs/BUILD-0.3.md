## 已实现

- 金额优先录入、日历选择日期、大类／细类选择面板、最近 6 个支出分类。
- 分类隐藏与恢复；隐藏大类同时影响其细类的新录入候选，历史记录及统计不受影响。

## 当前边界

- 备份格式版本为 1，导入上限 20 MB；整本覆盖，不做合并。
- 覆盖前副本只保留最近一次，存放于应用内，卸载会丢失。用户可主动导出。
- 最近分类根据记账日期倒序去重生成，不单独记录点击时间。
- 事件复盘、云同步、完整自定义分类等仍按需求排除在本版之外。
- 真实生活试记一周及不同品牌手机体验，留待安装后验证。
