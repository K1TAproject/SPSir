# SPSir 0.4.7

- 流水页和统计页共用“统计范围”：全部、仅含指定事件、排除指定事件。点击应用后同步生效，并记住上次选择。
- 流水记录继续完整显示，不纳入统计的记录标记“不计入统计”。月度、每日和搜索结果金额按同一范围计算，搜索不会改变月度卡片口径。
- 支持个人、公共及归档事件，不影响事件完整费用、公共结算或事件账单。
- 事件改名后范围继续有效；完整备份恢复成功后范围重置为全部，失败或取消则保留。

数据库和备份格式保持版本 4；统计偏好仅保存在本机，不包含在账本备份中。已安装正式版可先导出备份，再覆盖安装，无需卸载。

Android 8.0 及以上。发布附件：`SPSir-0.4.7.apk`、同次构建的 `update.json`。
